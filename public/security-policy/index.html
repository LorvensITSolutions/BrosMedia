Security policy

If you discover a security vulnerability on brosmedia.in, please report it responsibly so we can fix it quickly.

How to report

  • Email: info@brosmedia.in
  • Phone: +91 70138 14030

Include steps to reproduce, affected URLs, and any proof-of-concept details that help us verify the issue. Do not publicly disclose the vulnerability until we have had a reasonable chance to remediate it.

Formal contact details also live at /.well-known/security.txt.
